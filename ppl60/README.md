# PPL 60 · 推 / 拉 / 蹲

一个无构建步骤的静态训练计划页。所有动作演示均为内嵌 SVG 循环动画，不依赖 CDN、外链字体或自动播放视频，适合在微信内置浏览器打开。

## 本地预览

```bash
cd ppl60
python3 -m http.server 8788
# 打开 http://127.0.0.1:8788/
```

## 文件

- `index.html`：页面结构、文案、训练日内容容器
- `assets/styles.css`：视觉与响应式布局
- `assets/app.js`：动作库、替代动作、肌群热图、SVG 动画、进度记录
- `assets/cover.png`：分享封面（1200 × 630）

## 更新方式

直接改 `index.html` / `assets/app.js` / `assets/styles.css`，提交到 `gh-pages` 分支即可。没有打包步骤。

## 微信访问注意

- 页面本身无外链资源，HTTPS 下即可打开；`github.io` 在中国大陆的访问速度和稳定性因网络而异。
- 如果微信里加载慢或打不开，可把整个 `ppl60/` 目录原样上传到腾讯云 COS、阿里云 OSS、Cloudflare Pages 或自己的服务器；不需要改代码。
- 微信分享预览图使用 `assets/cover.png`；部分客户端需要页面部署后重新分享才会刷新缓存。

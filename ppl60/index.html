DAY 01 · PUSH

推日 胸 · 肩前 / 中束 · 三头 · 腹

卧推 → 上斜哑铃推 → 器械推肩 → 蝴蝶机 / 双杠 → 侧平举 → 过顶臂屈伸 → 斜凳卷腹 → Pallof。

热身 8′ 4′ 轻量热身 + 2′ 胸椎、肩胛、肩外旋 + 卧推 3–4 组递增。

卧推默认 4×8–12；第 3 / 7 周按动作卡里的“8 周安排”切换。

时间：热身 8′ → 卧推 15′ → 上斜 + 推肩 14′ → 夹胸 + 侧平举 10′ → 三头 + 卷腹 8′ → Pallof 5′ → 机动 10′

20–24正式组
65–70′总时长
RIR 2主项

DAY 02 · PULL

拉日 背 · 后束 · 二头 · 腹 · 抗侧屈

硬拉 → 对握引体 → 划船 → 后束 → 牧师凳弯举 → 斜凳卷腹 → 农夫行走。

热身 8′ 4′ 轻量热身 + 2′ 髋铰链、髋踝活动、肩胛下沉 + 硬拉 3–4 组递增。

硬拉只做力量组 3×3–5；不做 8–12 容量组。

时间：热身 8′ → 硬拉 15′ → 引体 + 划船 14′ → 后束 + 二头 12′ → 卷腹 + 行走 8′ → 机动 13′

20正式组
65–70′总时长
RIR 2硬拉 / 引体
MUSCLE MAP传统硬拉
主要发力稳定 / 辅助

DAY 03 · SQUAT

蹲日 腿 · 臀 · 内收肌 · 小腿

深蹲 → 分腿蹲 → 俯卧腿弯举 → 内收肌 → 提踵。

热身 8′ 4′ 轻量热身 + 2′ 髋踝活动、深蹲模式 + 深蹲 3–4 组递增。

深蹲 4×5–8；其余动作 8–12。

时间：热身 8′ → 深蹲 18′ → 分腿蹲 12′ → 腿弯举 + 内收 14′ → 提踵 6′ → 机动 12′

18正式组
60–70′总时长

主要发力稳定 / 辅助
